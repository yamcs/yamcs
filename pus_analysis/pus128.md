# PUS ST[128] — Two-line element sets

The simulator keeps the current two-line element set in memory. The PUS example MDB defines
the commands and reports in [pus128.xml](../examples/pus/src/main/yamcs/mdb/pus128.xml).

| Message | Simulator behavior |
|---|---|
| TC[128,1] | Store two consecutive 69-byte lines. |
| TC[128,2], TM[128,3] | Return the stored lines in the original byte order. |
| TC[128,4], TM[128,5] | Report the calculated checksum and validity for each line. |

The checksum sums the digits and counts each minus sign as one over the first 68 characters,
then takes the result modulo 10. The simulator compares that value with the digit in the last
character. In TM[128,5], each 8-bit numeric checksum is immediately followed by its one-bit
validity flag. The two entries occupy 18 bits, followed by six zero padding bits.

Report requests before the first upload produce a failed completion verification. Both commands
and reports reserve four zero bytes in the secondary header of the PUS example profile.
